## Blockers / decisions needed

1. MANE version choice: current/ serves **v1.5**, not v1.4 — decide whether to pin v1.4 (per original plan) or v1.5.
2. SpliceAI's bundled `grch38` annotation is GENCODE V24-era; for isoform-aware analysis a custom GENCODE v46/MANE annotation TXT is needed — non-trivial but documented (repo has `spliceai/annotations/grch37.txt` as template).
3. CADD whole-genome files are tens of GB; for 5k variants use tabix region queries or the REST API — do not bulk-download.
4. gnomAD v4.1 has no lightweight per-variant bulk file; GraphQL API is the practical route (rate limits untested here).
