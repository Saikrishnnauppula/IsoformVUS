Definitions. An exon's CDS interval is the overlap of the exon's GENCODE v46
span with the transcript's CDS features; `cds_length` is the number of CDS
bases in the exon. Script 18's only exon exclusion is its variant-level
`in_last_exon == 0` filter — it has **no** first-exon exclusion — so the
script-18-rule column mirrors the population its tensor draws from, and the
strict column is the primary definition used for the annotated tensor below.
For every strict-internal exon here, `cds_length == exon_length` (internal
exons are fully coding), so length bins and phase (CDS length mod 3) are the
same on either basis. Compare script 18: **4,593** reconstructed exons,
**4,509** called internal — more "internal" exons than the **3,965** CDS
exons that exist in these transcripts in total, because variant-gap
clustering fragments single annotated exons into several reconstructed ones.

## (iv) Annotated re-derivation of the 4x2x2 tensor

**Feasible in full.** Supp-table variants with mane_class_v46 == 'missense' were assigned to annotated internal coding exons by genomic position (pos inside the exon's annotated CDS interval, same gene). Length bin and phase symmetry (cds_length mod 3 == 0) come from the annotation. ## Limitations

- Backup skipping in the annotated tensor is script 18's variant-level expr_backup_skips quantity (a GTEx transcript-abundance fraction, not junction PSI), replicated exactly and held fixed so the tensor comparison isolates exon geometry; the GTF-direct sensitivity is the only place a different skip definition enters.
- The reconstruction replication is verified against the shipped candidates TSV as a (gene, length, symmetry, skip) multiset; reconstructed spans are therefore as script 18 computed them on the pinned stack, but exon_id numbering is not compared and may shift between genes.
- Annotated assignment uses the supp table's mane_class_v46 == 'missense' set (the same variant population as script 18's tensor) and its clnsig_aggregate resolved labels, unchanged.
- Phase symmetry uses annotated CDS length mod 3 (not script 18's refine_bounds-adjusted span); for strict-internal exons CDS length equals full exon length in this atlas.
